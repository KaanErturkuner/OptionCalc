# Kurullar

İki kurul, uygulamanın kalitesini ve para kazanma yönünü ayrı ayrı ele alır.

| Kurul | Dosya | Çıktı | Karar |
|---|---|---|---|
| Tester (7 üye) | `tester.md` | `bulgular.md` (bulgular ve düzeltmeler) | Düzeltme kendi kendine yapılır; para ve yayın kararları Kaan'da |
| Yenilik (6 üye) | `yenilik.md` | `oneriler.md` (fikirler, Kaan'ın onay kuyruğu) | Yalnız Kaan |

Genel kural: kurullar Kaan'ın yerine karar vermez. Kaan'ın onayı olmadan yayın, para kuralı değişikliği, maliyetli veri sağlayıcı ya da MarketData çağrısı yapılmaz.

Oturum başında: önce `bulgular.md` ve `oneriler.md` okunur, açık kalanlar ele alınır.
